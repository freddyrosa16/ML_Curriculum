# Clustering

**Status:** Original

## Why this matters

Clustering finds groups in data that nobody labelled: customer segments, topics in documents, colours in an image. You'll build the two classic methods by hand: k-means (hard assignments, fast) and Gaussian mixture models trained with Expectation-Maximization (soft assignments, can model clusters of different shapes). EM is one of the most important ideas in ML; you'll meet it again in HMMs next project. Then you'll see how scikit-learn and SciPy do the same thing in one line.

## Concepts to understand first

- **What does k-means actually do?** It alternates two steps: assign every point to its nearest centroid, then move every centroid to the mean of its points. It stops when nothing moves. Each step can only lower the total squared distance, so it always converges, but maybe to a poor local solution.
- **What is "intra-cluster variance"?** The sum, over all points, of the squared distance to the nearest centroid. Lower means tighter clusters. Adding clusters always lowers it, which is why "pick the k with the lowest variance" doesn't work and you look for an "elbow" instead.
- **What is a Gaussian mixture model?** A belief that the data was generated by picking one of k Gaussians (with probability $\pi_i$) and then sampling from it. Each Gaussian has its own mean and covariance, so clusters can be stretched or tilted ellipses.
- **What do the E and M steps do?** E-step: given the current Gaussians, compute for each point the probability it came from each cluster (its "responsibilities"). M-step: given those responsibilities, re-estimate each cluster's weight, mean and covariance as weighted averages. Repeat until the log-likelihood stops improving.
- **What is the log-likelihood?** The log of the probability the model assigns to the whole dataset. EM is guaranteed never to decrease it.
- **What is BIC?** $\mathrm{BIC} = p\ln n - 2\ell$, where $p$ is the number of free parameters, $n$ the number of points and $\ell$ the log-likelihood. It rewards fit but charges for complexity; the k with the lowest BIC wins.
- **What is agglomerative (hierarchical) clustering?** Start with every point as its own cluster and repeatedly merge the two closest clusters. The merge history forms a tree (a dendrogram); cutting it at a height gives you clusters. Ward linkage merges the pair that increases total variance the least.

## Tasks

### 0. Initialize K-means

**File:** `0-initialize.py` · **Function:** `initialize(X, k)`

- `X`: `(n, d)` data. `k`: positive int, number of clusters.
- **Returns** `(k, d)` starting centroids, drawn from a uniform distribution spanning each dimension's minimum to maximum. Make exactly **one** call to `np.random.uniform`, asking for a `(k, d)` sample, so results are reproducible with a seed.
- No loops. Return `None` on bad input.

```
>>> np.random.seed(0)
>>> initialize(X, 5)
array([[38.3674, 59.5023],
       [41.7424, 47.4548],
       [30.5378, 54.6003],
       [31.4094, 71.9938],
       [64.3194, 36.0344]])
```

### 1. K-means

**File:** `1-kmeans.py` · **Function:** `kmeans(X, k, iterations=1000)`

- Start from your `initialize` (copy the function into this file; the original task required this file to be self-contained).
- Repeat up to `iterations` times: assign each point to its nearest centroid, then move each centroid to the mean of its points. If a cluster ends up empty, re-initialize that centroid the same way as in task 0 (one centroid).
- Stop early when the centroids no longer change.
- **Returns** `(C, clss)`: `C` is `(k, d)` final centroids, `clss` is `(n,)` the index of each point's cluster. `(None, None)` on failure.
- At most 2 loops.

```
>>> np.random.seed(0)
>>> C, clss = kmeans(X, 5)
>>> C
array([[30.0672, 40.4112],
       [39.6277, 19.8984],
       [ 9.9251, 25.731 ],
       [20.0836, 69.8159],
       [59.2277, 29.198 ]])
```

### 2. Variance

**File:** `2-variance.py` · **Function:** `variance(X, C)`

- **Returns** the total intra-cluster variance: the sum over all points of the squared distance to the closest centroid in `C`. `None` on failure.
- No loops.

```
>>> variance(X, C)                          # C from task 1
7868.52...
>>> variance(X, X.mean(axis=0, keepdims=True))   # one centroid at the mean
157927.70...
```

### 3. Optimize k

**File:** `3-optimum.py` · **Function:** `optimum_k(X, kmin=1, kmax=None, iterations=1000)`

- Run your k-means for every k from `kmin` to `kmax` inclusive (`kmax=None` means the number of points). `kmin` must be smaller than `kmax`.
- **Returns** `(results, d_vars)`: `results` is a list of the `(C, clss)` outputs for each k, and `d_vars` is a list where each entry is the variance for `kmin` minus the variance for that k. `(None, None)` on failure.
- At most 2 loops.

```
>>> np.random.seed(0)
>>> results, d_vars = optimum_k(X, kmax=10)
>>> np.round(d_vars, 2)
array([     0.  ,  78189.04, 123143.47, 138470.21, 139204.76, ...])
```
Plot `d_vars` against k: the curve flattens after k = 5, the true number of blobs.

### 4. Initialize GMM

**File:** `4-initialize.py` · **Function:** `initialize(X, k)`

- **Returns** `(pi, m, S)`:
  - `pi`, `(k,)`: every cluster equally likely.
  - `m`, `(k, d)`: the centroids from your `kmeans(X, k)` (default iterations).
  - `S`, `(k, d, d)`: an identity matrix for every cluster.
- No loops. `(None, None, None)` on failure.

```
>>> pi, m, S = initialize(X, 4)
>>> pi, m.shape, S.shape
(array([0.25, 0.25, 0.25, 0.25]), (4, 2), (4, 2, 2))
```

### 5. PDF

**File:** `5-pdf.py` · **Function:** `pdf(X, m, S)`

- **Returns** `(n,)`: the multivariate Gaussian density with mean `m` `(d,)` and covariance `S` `(d, d)` at each row of `X`. Floor every value at `1e-300` so later logs never see 0.
- No loops, and no `np.diag` / `.diagonal()`. `None` on failure.

```
>>> pdf(np.array([[0., 0], [1, 1], [2, 0]]), np.zeros(2), np.array([[1, .5], [.5, 1]]))
array([0.1838, 0.0944, 0.0128])
```

### 6. Expectation

**File:** `6-expectation.py` · **Function:** `expectation(X, pi, m, S)`

- **Returns** `(g, l)`: `g` is `(k, n)`, the posterior probability of each point belonging to each cluster (each column sums to 1), and `l` is the total log-likelihood of the data.
- At most 1 loop. `(None, None)` on failure (including `pi` not summing to 1).

```
>>> g, l = expectation(X, pi, m, S)    # outputs of task 4
>>> g.shape, np.allclose(g.sum(axis=0), 1)
((4, 250), True)
```

### 7. Maximization

**File:** `7-maximization.py` · **Function:** `maximization(X, g)`

- **Returns** `(pi, m, S)` updated from the responsibilities `g` `(k, n)`: cluster weights `(k,)`, weighted means `(k, d)`, weighted covariances `(k, d, d)` (divide by the total weight of the cluster, not "minus one").
- At most 1 loop. `(None, None, None)` on failure (including columns of `g` not summing to 1).

```
>>> pi, m, S = maximization(X, g)
>>> pi.shape, m.shape, S.shape, np.isclose(pi.sum(), 1)
((4,), (4, 2), (4, 2, 2), True)
```

### 8. EM

**File:** `8-EM.py` · **Function:** `expectation_maximization(X, k, iterations=1000, tol=1e-5, verbose=False)`

- Initialize with task 4, then alternate expectation and maximization up to `iterations` times. Stop early when the log-likelihood changes by `tol` or less.
- If `verbose`, print `Log Likelihood after {i} iterations: {l}` (rounded to 5 decimals) after iteration 0, every 10 iterations, and after the last iteration.

- At most 1 loop.

```
>>> pi, m, S, g, l = expectation_maximization(X, 5, verbose=True)
Log Likelihood after 0 iterations: ...
Log Likelihood after 10 iterations: ...
...
```

### 9. BIC

**File:** `9-BIC.py` · **Function:** `BIC(X, kmin=1, kmax=None, iterations=1000, tol=1e-5, verbose=False)`

- Run EM for every k from `kmin` to `kmax` inclusive (`kmax=None` means the number of points). `kmin` must be smaller than `kmax`.
- The number of free parameters of a k-component, d-dimensional GMM: k·d for the means, k·d(d+1)/2 for the covariances, k−1 for the weights.
- **Returns** `(best_k, best_result, l, b)`: the k with the lowest BIC, its `(pi, m, S)`, and arrays of the log-likelihood and BIC for each k tried. Four `None`s on failure.
- At most 1 loop. Careful: `best_k` is an actual k, not an index, and must be right even when `kmin` isn't 1.

```
>>> best_k, best_result, l, b = BIC(X3, kmin=1, kmax=5)
>>> best_k, l.shape, b.shape
(3, (5,), (5,))
```
